This is a distribution bundle of Android artifacts and update documentation, not a full source-code
checkout or Git-history bundle.

The APK includes the Live device report (menu → Live device report), refreshed every second without
USB/ADB or network. Generation is permitted through Severe (3), blocked at Critical (4)+, and an
active job is cooperatively cancelled when Critical+ is detected. API 26–28 explicitly reports
thermal telemetry unavailable. This is compiled/JVM-tested behavior only; Galaxy S24 device acceptance
remains BLOCKED/UNVERIFIED.

Install/signing warning: the included APKs use local debug signing certificate SHA-256
960c75a9648a74dc189f3510a6c7f80e7029a63680b5dbdea0a2d87b244e5514. The preceding artifact set used a
different certificate, so Android may refuse an in-place update. Export any saved avatars before
uninstalling an older app; uninstalling can erase app-private data.
